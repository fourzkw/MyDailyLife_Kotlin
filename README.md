# MyDailyLife（Kotlin）

日程 + 课表 + 统计的 Android 日常工具，使用 **Kotlin / Jetpack Compose / Material3** 实现。

**当前版本：`1.14.5`（`versionCode` 34）**

面向协作者与 AI 的工程约定见 [`AGENTS.md`](AGENTS.md)。

---

## 功能概览

| 模块 | 能力 |
|------|------|
| **日程** | 周条 / 下拉月历、待办与已完成、课程同步显示、综合 / 时间 / 紧急度排序、Once·Daily·Weekly 提醒 |
| **课表** | 教学周滑动、长按选格加课、详情编辑与删除、清空课表、Excel·CSV·xlsx·xls / ICS 订阅与导出 / 教务选校导入、上课时间预设、上课提醒 |
| **统计** | 聚合概览 |
| **设置** | 外观主题切换、通知权限与精确闹钟引导、默认优先级、标签、应用内检查更新 |
